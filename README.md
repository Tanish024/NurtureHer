<h1>NurtureHer</h1>
<br>
About the Project
<br>
<h2>NurtureHer is a dedicated website designed to support women during pregnancy by providing essential healthcare services and information. The platform aims to make pregnancy care more accessible and stress-free.</h2>
<br>
<h1>Features</h1>
<br>
Appointments: Schedule and manage doctor consultations with ease.
<br>
Hospital Locator: An interactive map to find nearby hospitals.
<br>
Partnered Hospitals: List of hospitals collaborating with NurtureHer for seamless healthcare.
<br>
Blood Donation Support: Integrated blood donation site for emergency needs.
